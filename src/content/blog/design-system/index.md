Hi, welcome to my new blog! In this blog, I have shared my personal design stack that I use the most in almost all of my design work. These include the choices of fonts, colors, icon and UI libraries after trying and picking the best ones here that seems to be better overall. Let's look at them one by one.

## Fonts

For the most of my time when I design, I had been stuck with the Inter font because of its perfection in design built to be used by anyone and anywhere so it became hard for me to switch over to other fonts. Now, I have started to build one habit to explore for different, unique yet hidden fonts that might take either one X post or would take even days to find the perfectly looking one. Some of the main fonts from my recent findings that I am using these days are:

### Display

1. Bricolage Grotesque
2. Instrument Serif
3. Inter Display
4. OGG
5. Fraunces

### Monospace

1. Jetbrains Mono
2. Fira Code

### Sans-serif

1. Geist Sans
2. Inter

### Serif

1. Lora

## Colors

I, generally, prefer black and white with its shades in most of my designs but I have started looking for more vibrant combinations that give energy to the design and comfort to eyes with proper contrast and shades. I have been loving these websites which gives ready to use color palettes to use directly in designs without giving much of my time thinking about the perfect color blend that'll align smoothly with others.

1. [Color Hunt](https://colorhunt.co/)
2. [Coolors](https://coolors.co/palettes)
3. [Canva](https://www.canva.com/colors/color-palettes/)

## Icon Libraries

Below 3 are my go-to libraries for icons. I generally prefer Lucide library for websites as it mostly covers the need but if it doesn't show up with the one that I am looking for, then I prefer to go to Phosphor library which definitely has this already built out. I know this might be conflicting and can create inconsistencies among icons in the design but they look and feel pretty similar so I go in this order. And lastly for brand logos, first Simple icons library, if not found, then go to the official website's asset page to get them.

1. [Lucide Icons](https://lucide.dev/icons/)
2. [Phosphor Icons](https://phosphoricons.com/)
3. [Simple Icons](https://simpleicons.org/) - for logos
